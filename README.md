# Skills

A small collection of agent skills I built for my personal workflows.

[![skills.sh](https://skills.sh/b/kevin-lann/skills)](https://skills.sh/kevin-lann/skills)

## Install

```bash
npx skills add kevin-lann/skills
```

## Included

**flow-diagram** — describe a flow and get one self-contained HTML diagram: user journeys, code paths, request traces, and concept explainers. No dependencies, no hand-placed boxes. See [`flow-diagram/examples/`](flow-diagram/examples/) for the output.
