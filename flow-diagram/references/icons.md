# Icon catalog

113 Lucide icons (ISC licence), drawn on a 24px grid at 1.75px stroke. Only these names resolve — `route`, not `router`; `circle-check`, not check.

Pick the icon for the **noun**, not the verb: a payment node gets `credit-card`, not `zap`. If no noun fits, use `box` (a component) or `circle-dot` (an event) rather than something decorative.

## Pairings that read well

| Concept | Icon |
|---|---|
| API / service | `server` |
| background worker | `cpu` |
| queue / stream | `layers` |
| object storage | `cloud` or `archive` |
| third-party payment | `credit-card` |
| webhook | `webhook` |
| auth / session | `shield-check` |
| token / secret | `key-round` |
| browser action | `mouse-pointer-click` |
| success terminal | `circle-check` |
| failure terminal | `circle-x` |
| expired / timeout | `clock` or `timer` |
| audit trail | `list` or `file-text` |
| deploy | `ship` or `upload` |

## Don'ts

- No emoji, no coloured emoji fonts.
- No two different icons for the same concept in one diagram.
- No icon on an edge.
- Do not pick `sparkles`, `zap` or `brain` as decoration. They read as AI-generated filler.
